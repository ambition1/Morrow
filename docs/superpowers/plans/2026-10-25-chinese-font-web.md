# 简体中文、字体与 Web 支持实施计划

> 在当前会话逐项实现并验证。

**目标：** 完整简中界面、自定义本机字体和可独立部署的 Web 应用。

**架构：** 复用现有 i18n，新增 zh-CN 完整词典及启动文案；字体偏好保存到现有设置，在根元素应用字体变量；浏览器通过认证 HTTP 桥接复用 VaultRepository，服务端按账号隔离文件目录，桌面保留原生桥接。

**技术栈：** React、TypeScript、Vite、IndexedDB、Vitest。

- [x] 简中词典：新增 src/app/i18n/locales/zh-CN.ts，注册语言、默认简中、设置文档语言，测试键和插值一致性；排查欢迎页和硬编码文案。
- [x] 字体：修改 preferences.ts、Settings.tsx、App.tsx 和 tokens.css，默认系统字体；支持界面及正文自定义字体名、安全 CSS 字符串序列化、即时应用和刷新保留。
- [x] Web：main.tsx 根据 desktop 选择仓库，多账号登录与服务器磁盘持久化；保留附件、历史、备份和导入导出，增加版本冲突保护；桌面专属操作隐藏或解释原因。
- [x] 交付：增加 dev:web/build:web/preview:web 脚本和部署文档；运行类型检查、测试、lint、Web 构建及浏览器实际验收。

**Web 行为约定：** 用户要求远程服务器部署、多账号独立笔记库。管理员创建账号，使用 scrypt 密码摘要和 HttpOnly Cookie；服务器认证后决定笔记库目录，所有文件路径检查并拒绝符号链接；写入串行且检查工作区身份及版本，陈旧客户端不能覆盖新版本；同账号其他设备更新后提示刷新。单实例部署，提供 Docker Compose 与 HTTPS 代理说明。

**验证结果：** 简中词典键与参数一致，中文密码/存储错误、中文计数、字体与服务器隔离回归通过。Web 页面实际验证中文登录、编辑落盘、刷新及服务重启恢复、字体计算样式。提供 Docker Compose、管理员建号命令和 HTTPS 部署文档。实际远程部署待服务器连接信息。
