# 附件多模式预览实施计划

**目标：** 为现有附件增加默认侧边、正文内嵌和大窗三种只读预览，保留笔记编辑与下载。

**架构：** 附件节点提供入口及内嵌挂载点；应用级预览宿主管理模式、关闭与宽度。引擎按需加载，从当前 session 读取附件生成 File，避免依赖桌面自定义协议的 fetch。复用 Select、Dialog、主题令牌与四语词典。

**技术：** React 19、Vite 8、File Viewer 3.3.3，standard 预设及 drawing/mindmap 渲染器。

## 验收重点

侧边查看时笔记可编辑，切换模式不改正文；关闭恢复布局。内嵌预览不进入 ProseMirror 文档与导出内容。不支持或失败的文件保留下载。切换文件与关闭取消过期读取。重型解析器仅在预览时下载；资源随构建本地发布。邮件/HTML 不运行文档脚本，不请求外部资源。压缩包不写入用户笔记库。
