# 文档编辑扩展统一计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 在现有 Morrow 编辑器中完成提示块增强、紧凑斜杠菜单、图册，以及前轮 B「结构化排版」、C「资料卡片与图片」的全部约定范围。

**Architecture:** 复用 Tiptap、现有提示块、分栏、折叠、页面链接及附件存储，先确定文档兼容和保存规则，再扩展交互。图册作为独立文档内容块，不作为数据库视图。共用的图片能力只实现一次，覆盖单图和图册。

**Tech Stack:** React、TypeScript、Tiptap/ProseMirror、现有语义 CSS 变量、Markdown 文件存储及 Web VaultBridge。

作者：xuanli；计划日期：2026-10-29。

**状态：已实现，完成集成与浏览器验收。** 勾选表示范围已交付；实际执行的检查及限制以验收记录为准。 用户所指 B、C 对应上一轮「项目执行手册」「旅行资料与参考」两张图；本计划把它们与最新三张设计合并，不重复开发。实现代码已落地；测试使用独立临时笔记库，未修改真实笔记内容。

## 顺序和任务边界

1. Task 1确定数据契约，先让旧文档与新增样式能够安全往返。
2. Task 2提示块、Task 3菜单、Task 4图册可分区推进，但对序列化和公共菜单的修改由主集成者统一协调。
3. Task 5落实B结构化排版；Task 6落实C引用／资料卡片，其图片部分依赖Task 4，不重复实现。
4. Task 7覆盖全部模块后统一交付；所有范围都在本计划内，顺序不代表取消B、C或只完成前三项。

本次已按「提示块」「斜杠菜单」「媒体与图册」「结构与引用」划分subagent并行实现，主集成者负责模型、解析序列化、翻译、浏览器验收和提交。详细检查结果与实际截图见[验收记录](../../design/editor-blocks/ACCEPTANCE.md)。
