# Docker Compose 部署完善计划

**目标：** 提供可运行的远程 HTTPS 部署、本地调试、账号管理及安全的数据迁移流程。

**约定：** 保留原 `morrow-data` 数据卷和单实例架构；基础 Compose 为已有 HTTPS 代理提供回环端口；HTTPS 叠加文件增加 Caddy；本地 HTTP 仅通过独立叠加文件开启。账号密码不写入 Compose 或 .env。恢复仅写入新的空数据卷。

- [x] 新增无敏感信息的健康接口和容器探针，验证未认证也可探活、缺失构建时不健康。
- [x] 完善 Dockerfile 与 Compose 的健康、日志、停止宽限期和文件系统限制；增加 .env.example、本地/HTTPS 叠加配置和 Caddyfile。
- [x] 提供管理员操作脚本，覆盖启动、状态、建号、一致性备份和空卷恢复，失败时恢复原先运行状态。
- [x] 重写部署文档，说明 DNS/端口、持久化、升级回滚、迁移与故障诊断。
- [x] 实际验证 Compose 启动、认证、多账号、TLS、容器重建持久化及备份恢复；审查后提交推送原功能分支。

**验收结果：** 基础/本地/HTTPS Compose 配置通过校验；只读根容器健康、建号、中文页面与附件持久化通过；容器重建与新卷恢复通过；非空卷与并发操作被拒绝；故障注入证明备份失败后恢复服务并清理临时文件和锁；本地 CA 验证 HTTPS、Secure Cookie、Host 保留、HTTP 308 及 CSRF。真实公网域名的 ACME 申请需在目标服务器 DNS 配置完成后验证。
