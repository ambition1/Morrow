# 文档内容块扩展验收

作者：xuanli；日期：2026-10-30。

## 交付内容

- 原提示块支持预设、九色与自定义 HEX、独立边框、图标、标题显示及折叠。
- 斜杠菜单支持最近使用、T／H1–H6 紧凑格式区、双列内容区、搜索及视觉顺序键盘导航。
- 图册支持网格、瀑布流、轮播、追加上传、失败重试、排序、逐图与整组图注；单图复用设置、预览与附件下载。
- B：分栏比例、分隔线调宽、栏背景、步骤列表；沿用任务清单、折叠与目录。
- C：动态本地笔记卡片及行内／嵌入切换、手动网页摘要和本地封面；沿用附件和 PDF 预览。
- 扩展属性通过安全配对注释保存，正文保留可读 Markdown。图册导出含全部图片，备份与附件映射复用原实现。

## 验证证据

`npm run check`：23 个测试文件、209 项测试通过；类型、ESLint、桌面前端／Electron／MCP 构建通过。

`npm run test:web`：服务器集成测试通过。`npm run build:web`：Web 构建通过。

临时服务器 `127.0.0.1:3198` 使用独立临时笔记库与本地测试图片，未修改 3188 的用户笔记。浏览器实际检查了提示块改色、折叠、保存重开；分栏键盘调宽、手机纵向排列；菜单中文搜索、Enter 执行；图册本地文件上传、布局切换、轮播与预览翻页；网页卡片编辑保存。检查尺寸包括桌面 1400×1000、768×900、375×812 及短屏菜单，浅色和模拟系统深色均检查。

回归测试覆盖旧提示块默认输出、新属性往返、分栏嵌套、图册图片和图注、卡片页面／附件重映射、静态发布所有图片、危险 URL、损坏注释及外部新增正文保留、图册排序一次撤销、异步操作转只读后禁止写入。独立审查发现并修复了外部 Markdown 正文可能被吞、图册异步回调和分栏提交未重验编辑权限的问题。

不是所有浏览器／移动真机都已实测。拖放取消、上传失败重试及减少动态效果分支做了代码检查；上传成功、键盘调宽与排序撤销分别有浏览器或自动化证据。网页卡片为手动摘要，不提供自动抓取。
