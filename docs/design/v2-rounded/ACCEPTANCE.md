# 第二版实现验收

## 验收约束

概念图用于比较布局和视觉层级，不要求把示例内容写入用户库。真实数据的字段名、状态颜色、字体与主题偏好继续有效。编辑与新增测试使用临时数据副本，真实库仅作只读展示。

## 检查清单

- [x] 桌面侧栏和主内容区各有完整24px圆角，外沿和面板间距10px。
- [x] 独立数据库使用可用宽度，标题紧凑；内嵌数据库和笔记阅读宽度不变形。
- [x] 视图切换与工具区分层，新建、字段、筛选、排序对应真实已有行为。
- [x] 表头类型图标、行序号和单元格选中态清晰，静止日期/数字单元格没有浏览器默认控件皮肤。
- [x] 单元格可通过键盘激活、提交、取消；Escape后失焦不提交取消值，Enter后不会重复保存。
- [x] 新增行后的名称编辑可用，打开记录按钮不会误触发其他编辑。
- [x] 看板、日历、画廊、列表正常展示，窄屏保留内部滚动；既有拖拽绑定经代码审查保留。
- [x] 笔记标题和正文形成稳定阅读轴，大纲可以跳转并在窄屏隐藏，封面与每日笔记不遮挡。
- [x] 浅色、深色、375px、768px及短屏布局检查，分栏不挤压正文或丢失工具按钮。
- [x] 设置、菜单、免登录访问和保存冲突保护没有回归。
- [x] 完整类型、lint、测试、构建、Web服务回归通过；独立代码审查的具体问题已修正。

## 自动检查

使用 `npm run check` 验证类型、lint、单元测试及完整构建；使用 `npm run test:web` 验证免登录原存储路径、写入版本、附件和路径边界；使用 `npm run build:web` 更新运行时静态页面。

## 本轮结果（2026-10-28）

- `npm run check` 通过：TypeScript、ESLint、19个测试文件/184项测试以及桌面、前端、MCP构建。
- `npm run test:web` 通过：Web服务集成回归（1项集成测试包含多段断言）。`npm run build:web` 通过。
- 使用3191端口的临时笔记库副本检查了表格、看板、日历、画廊和列表；375×720、768×720、375×360短屏、1280×800桌面及1512×900宽屏均有实际浏览器检查。
- 数字属性Escape取消后仍为空，Enter保存2.5并返回单元格焦点；切换视图后数值保留。表格已有排序时，分屏左侧新增行正确聚焦左侧新记录，名称提交后两侧同步。
- 大纲在宽屏显示、手机隐藏，点击可定位正文；筛选弹层、设置短屏独立滚动、视图切换与免登录加载正常。
- 独立审查指出的URL外链入口、中文输入法组合输入、失焦抢焦点及全局新增行焦点问题均已修正，最终复核没有阻塞问题。
- 所有编辑仅在临时副本进行；真实库12个Markdown/画布文件前后SHA-256完全一致。
