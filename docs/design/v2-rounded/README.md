## 实现约束

- 保留主界面两块独立的24px圆角面板，外沿与面板间留8–12px间距。手机使用满宽正文与原有圆角抽屉。
- 颜色、字体和玻璃效果复用现有令牌。正文和数据网格保持实色；玻璃限导航与浮层。尊重深色、减少动态、减少透明度及自定义字体偏好。
- 笔记和数据库使用不同内容宽度。独立数据库占满可用工作区，内嵌数据库仍跟随笔记版心，舒适阅读偏好不被数据库布局修改。
- 优先使用现有属性类型、视图、排序、筛选和记录操作。示意中的行高选择、查找或聚合等没有实现基础的控件不能仅为匹配图片而出现。
- 新增只读大纲可以从现有标题生成，跳转不能修改正文或持久化新数据。移动端和窄分栏隐藏大纲，避免挤压正文。
- 表格静止时不展示浏览器默认日期/数字输入皮肤；激活后沿用原属性编辑器。保留键盘聚焦、编辑、提交、取消以及数据保存语义。
- 不恢复登录、用户、复习；不迁移存储，不添加实时协作或权限系统。所有示例内容仅存在于概念图，不能写入用户笔记库。

## 实施分工与验收

主代理负责共享圆角外壳、样式集成、翻译、浏览器验收及交付。三个subagent分别负责笔记阅读区、数据库表格与单元格、数据库看板/日历/画廊。文件边界见 [实施计划](../../superpowers/plans/2026-10-28-rounded-workspace-v2.md)。

对照图片检查布局、文字层次、视图与工具栏、选中/编辑态、圆角和材质。实际验证桌面、768px、375px和短屏，检查浅/深色、键盘操作、筛选/排序、不同视图、菜单与设置回归。验收记录与真实截图保存在本目录的验收文档中。
