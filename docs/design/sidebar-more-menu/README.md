# 更多功能就近菜单

作者：xuanli；日期：2026-11-01。

根据用户参考图，将更多功能从右侧整高抽屉改为按钮旁的紧凑弹出菜单。复用 Menu、现有图标和圆角材质，默认 right-start 定位；保留搜索快捷键、标签、关系图谱及已启用的桌面助手。点击条目、外部区域或 Esc 关闭，重复点击入口可切换。

移除专用抽屉 CSS。共享 Menu 在定位可见后聚焦首项，避免隐藏时聚焦无效；异步定位完成前已卸载时不抢焦点。横纵两个方向均避让视口，375px 手机菜单范围 x147–367，距右边8px。

验收：类型、ESLint、Web构建通过；实际浏览器验证标签跳转、方向键、Esc返回入口，1151px浅色/深色与375px手机布局。截图来自独立测试库，不修改真实笔记内容。
