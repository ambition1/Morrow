# 每日笔记年月目录

作者：xuanli；日期：2026-10-30。

侧边栏“每日笔记”采用“年份 → 月份 → 日期”虚拟层级，年、月、日期均按新到旧排列。年月行显示笔记数量并可折叠，默认展开活动日期所在月份，没有活动日期时优先展开最新月份。

- 打开日期时自动展开其年月并将选中项滚入目录；手动折叠当前年月不会切换正文，切到另一篇或返回历史日期后重新揭示活动路径。
- 展开偏好保存在现有界面设置中。当前活动路径优先于过往折叠偏好，避免打开笔记后找不到目录位置。
- 默认日期标题在年月分组内简写为“30日 周五”；自定义标题及完整可访问名称保留。
- 年月没有页面ID，不创建真实页面、不改变parentId、文件路径、链接或现有笔记内容。普通子页面和异常日期仍留在原目录，不被分组吞掉。
- 支持上下键遍历、左右键展开／折叠及回到父级，Enter／空格切换年月，Enter打开日期。虚拟组不提供重命名、删除或拖放目标。
