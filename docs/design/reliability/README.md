# 笔记可靠性首轮交付与验收

作者：xuanli；日期：2026-10-30。

## 已实现

- 已打开的 Web 笔记在命令入队时保存独立 IndexedDB 草稿，包含正文、页面元数据、共同基准、版本和更新时间。按浏览器来源、稳定库身份、每次页面启动身份与页面 ID 隔离，不修改现有笔记存储目录。
- 服务器确认后只清除对应代数；新编辑、迟到响应、不同标签和其他页面的存储失败分别处理。容量不足或隐私模式禁用数据库时显示保护失败，不伪装为已存本机。
- 保存状态区分服务器保存、本机保护、保存失败和冲突。重新打开时发现旧草稿；恢复窗口可复制正文、下载 Markdown、保留为副本或手动合并。合并前保留服务器当前正文版本，服务器成功后才移除旧草稿。
- Web 文件冲突停止自动覆盖与重放。保留服务器与本机内容，先确认本机保护再重新加载服务器。更新后仍由普通版本校验保护，不提供强制全库覆盖。
- 草稿恢复沿用原内容节点；手动合并用可读 Markdown 和受限附件引用往返，保留日期、图册、附件、封面与笔记引用。页面属性不随正文合并覆盖；副本放在根目录。
- 加密前若存在任何标签的未同步副本，拒绝加密并要求处理。已加密页面不新增明文草稿；启动发现服务器已加密时阻止旧标签继续写明文，同时保留加密前尚未同步的旧副本供用户处理。取消加密后恢复普通草稿保护。
- 全文搜索增加页面及其后代范围、标签、修改日期和图片／PDF／其他文件筛选。每个片段保存精确位置及文档校验，内容变化时退回文字查找。
- 快速记录可选择位置和添加图片／附件；原始文件与输入保存到本机。追加正文、整页草稿和清理输入之间设持久化检查点，断网重试不重复追加已提交正文或附件引用。
- 部署脚本提供自动备份、保留策略及最近成功状态，复用发布／恢复锁；调度配置见 [Web 部署](../../WEB部署.md)。未擅自安装系统任务。

## 验证证据

- 完整类型、ESLint、28个测试文件270项单元测试及前端／Electron／MCP构建通过；Web构建通过。
- Web 服务测试检查免登录共享、陈旧写入拒绝、附件边界和重启；新增稳定库身份跨重启一致验证。
- 草稿存储与协调器回归覆盖重开、多个所有者、迟到回执、跨页／同页存储失败、配额、数据库不可用、加密标记、跨连接事务、附件字节往返和快速记录检查点。
- 自动备份5项隔离测试通过。真实 Docker 使用两个临时项目和空目标卷恢复，笔记、附件、版本历史及回收站各1项，正文一致；临时项目及卷已清理。
- 浏览器使用 `localhost:3199` 与独立临时笔记库。实测断网编辑、本机保存状态、双标签同页冲突、重新打开发现草稿、保留副本、搜索后选择第二处命中文字、指定快速记录位置、附件上传失败及联网重试。重试后服务器正文仅出现一次快速记录。另实测手动合并后附件仍为可下载节点，合并前正文保留为版本；最终版“保护草稿并刷新”成功重新加载服务器、再次发现旧草稿，并验证明确采用服务器内容后只清理所选草稿。
- 检查1151px浅色桌面、768px深色和375×640短屏，375px页面宽度与滚动宽度均为375，无横向溢出。快速记录失败提示、附件与保存按钮可达；恢复窗口正文可内部滚动。
- 测试只操作临时数据，测试主题和视口在结束时恢复。

## 尚未完成及明确边界

- 当前待上传文件的跨刷新保护覆盖快速记录；普通正文图片／图册上传失败的独立持久上传队列仍需后续接入，不能把所有上传入口都宣称为离线可恢复。
- 已审计库级版本导致的不同页面冲突。本轮保留该保守校验，以维护布局、重命名和工作区元数据的多文件一致性；不同页面编辑仍可能要求保护后刷新，未改为页面级并发或自动合并。
- 双浏览器连续第三方修改、冲突时重命名／移入回收站的完整人工矩阵尚未完成；相关旧服务器与存储回归通过，不替代全部界面验收。
- 完整离线启动、PWA安装、OCR、PDF全文、录音识别、场景模板扩展、批量归档、附件引用查看和共享摘要均未纳入本轮。
- 自动备份工具与恢复演练已完成，实际定时任务须在目标服务器按部署文档配置；未将当前开发机器当作生产调度目标。
