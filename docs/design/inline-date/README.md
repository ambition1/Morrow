# 文档内日期与时间

作者：xuanli；日期：2026-10-30。

在正文输入 `/日期`（也可搜索 `/时间`），插入带日历图标的日期标签并打开选择面板。点击已有标签可原地修改日期，支持前后月份／年份、今天、明天、+7 天，勾选“时刻”后设置24小时制时间。按完成、Escape 或点击外部关闭。

日期是选定的固定值，不是实时走动的时钟，也不随“明天”等相对文字自动变化。新组件不创建或跳转每日笔记；旧的日期提及链接保留兼容。

保存使用可读的 HTML `time`，日期与时刻不进行 UTC 转换；搜索、备份、Markdown 及静态发布均保留显示内容。

验收：新增8项测试覆盖闰日、非法日期／时刻、日期与时刻保存往返、旧链接、无效标签正文保留及静态发布；完整217项测试通过，类型、lint、Electron／MCP及Web构建通过。服务器测试通过。浏览器使用独立临时库，验证了斜杠插入自动展开、键盘选日、时刻修改、快捷日期、保存重开及同一文档URL保持不变。桌面浅色、768px深色和375×640短屏均检查；手机浮层无横向溢出，时刻与完成按钮完整可见。只读入口与迟到回调均检查编辑权限。
