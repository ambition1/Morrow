# 正文优先显示

作者：xuanli；日期：2026-11-01。

有正文的页面不再追加自动子页面、反向链接、未链接提及和每日笔记的“此日创建”列表，减少阅读干扰。正文内用户主动插入的链接保持不变，侧栏仍可访问子页面。空白容器页保留自动导航，数据库使用自己的数据视图，不再附加关联列表。无法读取正文时不展示空白容器导航。

复用 isDocEmpty 判断正文，隐藏规则随保存到工作区的文档内容更新，不删除任何笔记或链接数据。

类型检查、ESLint、Web构建通过。独立临时库实际验证：有正文页面的自动分区为0；新建的空白容器仍展示示例子页面。1151px浅色、768px深色和375px手机检查，未改动真实笔记。
