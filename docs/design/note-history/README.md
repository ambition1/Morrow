# 笔记修改历史验收

作者：xuanli；日期：2026-10-30。

## 使用方式

打开笔记右上角“页面选项 → 版本记录”。

- 编辑时沿用已有自动记录机制，普通版本保留最近50个。
- 输入可选名称，点击“保存当前版本”；手动版本默认保留。
- 选中历史后可重命名，或切换“保留此版本／取消保留”。保留版本不参与普通数量清理，取消保留后可按普通规则清理。
- 差异只比较可读正文文字，布局和格式通过“该版本”预览查看；预览链接不改变当前文档。
- 恢复前先保存当前修改，再生成保留的“恢复前版本”。正文落盘成功才报告恢复成功。

## 范围与存储

本轮仅增强笔记修改历史，不新增软件更新日志。正文中的日期、提示块、图册及引用仍用原节点保存。页面属性、标题和数据库结构不随正文恢复。加密笔记不新增明文手动或恢复前版本。

文件库沿用 `.morrow/history/<页面ID>.json`，新增名称、来源、保留标记均为可选字段，旧历史继续可读。部署脚本的整库备份包含这些文件；现有界面JSON备份不包含版本历史，不应将其当作历史备份。

每次读取最新历史；写入按版本ID合并并校验磁盘原文，修改元数据还校验版本基准。发生并发变化时拒绝覆盖。Web仍沿用既有库级版本保护，遇到其他设备更新可能需要先保护草稿再刷新页面；本轮没有实现完整的文档冲突合并。

历史读取失败与空列表分别展示；损坏历史不会被当成空文件覆盖，失败操作保留名称输入，不发布未落盘的版本缓存。
