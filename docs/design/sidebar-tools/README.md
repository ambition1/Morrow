# 主导航与更多功能抽屉

作者：xuanli；日期：2026-10-30。

侧栏主要功能按“首页 → 今天 → 任务 → 更多”排列。搜索、标签和关系图谱收进“更多功能”右侧圆角抽屉；桌面端已启用的助手入口也随次要导航收纳。底部导入、回收站与设置继续保留。

抽屉复用现有Dialog的遮罩、焦点陷阱、Esc关闭与焦点返回行为，功能列表使用既有NavItem及语义令牌。选择功能后自动收起；搜索快捷键继续可用，快捷键或其他全局对话框打开时收起抽屉，避免两层焦点陷阱。

验证：类型检查、ESLint、Web构建通过；i18n的6项测试通过。独立临时库浏览器验证主导航顺序、抽屉三个入口、选择后关闭、Esc焦点返回，以及抽屉中按搜索快捷键只保留搜索面板。浅色、768px深色和375px手机布局均检查；手机抽屉320px宽、距右边10px，无横向溢出，关闭后返回原移动侧栏。未修改真实笔记内容。
