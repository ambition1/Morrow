## 前进后退移除（后续调整）

根据用户反馈，进一步删除工具栏的前进后退按钮、命令面板操作、快捷键及鼠标历史键拦截；导航状态不再维护前后记录。启动时“上次离开的位置”直接恢复保存地址，现有分栏继续保留。

类型检查、ESLint、Web 构建通过；30 个测试文件共 278 项测试通过。独立临时库实测桌面浅色、375px 手机深色，工具栏不再包含历史按钮，手机无横向溢出，浏览器控制台无错误。
